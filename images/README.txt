[이미지 파일 넣는 방법 - 웹툰 전용]

소설/뉴스는 이미지 없이 글만 표시되도록 변경되어서, 이제 이미지 파일은 웹툰에만 필요해요.

폴더 구조 (webtoon_app.html과 같은 위치에 images 폴더를 두세요):

images/
  webtoon/
    cat/    ep01_p1.jpg ~ ep10_p4.jpg   <- 고양이 집사 일기, 화당 4컷
    idol/   ep01_p1.jpg ~ ep10_p4.jpg   <- 아이돌 연습생 다이어리, 화당 4컷

규칙: images/webtoon/{작품id}/ep{회차 2자리}_p{컷번호}.jpg
예) 아이돌 연습생 다이어리 3화 2컷 -> images/webtoon/idol/ep03_p2.jpg

- 지금 들어있는 샘플: 고양이 집사 일기 1화, 아이돌 연습생 다이어리 1화 (각 4컷)
- 나머지(2~10화)는 아직 이미지가 없어서 "이미지 준비중" 표시가 대신 나와요. 정상입니다.
- 파일 이름과 폴더 위치만 규칙에 맞으면 코드를 수정하지 않아도 자동으로 반영돼요.
